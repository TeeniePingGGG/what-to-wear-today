# what-to-wear-today

# 👗 오늘 뭐 입지? (What to Wear Today?)

> **"매일 아침 '오늘 뭐 입지?' 고민하는 시간을 제로(0)로"**  
> AI 기반 내 옷장 데이터 연동 & 실시간 날씨·일정 맞춤형 코디 자동 추천 서비스

---

## 📌 프로젝트 개요 (Project Overview)

### 1. 배경 및 필요성 (Background)
* **아침 마다 반복되는 선택 장애**: 대학생 및 직장인 다수가 매일 아침 출근·등교 전 날씨와 당일 일정에 맞는 옷을 선택하는 데 많은 시간을 소요합니다.
* **보유 의류 파악의 한계**: 옷장에 옷은 많지만 정작 어떤 옷이 있는지 한눈에 파악하기 어렵고, 매번 입던 조합만 반복해서 입는 경향이 있습니다.
* **기존 패션 앱의 한계**: 기존 추천 서비스 대부분은 **'새로운 옷 구매(쇼핑몰 연동)'**를 유도하지만, 정작 사용자에게 필요한 것은 **'이미 내가 가지고 있는 옷'**으로 당장 입을 수 있는 현실적인 조합입니다.

---

### 2. 프로젝트 소개 (Introduction)
**"오늘 뭐 입지?"**는 스마트폰으로 내 옷 사진을 찍어 등록해 두면, **Vision AI**가 배경을 제거하고 카테고리·색상·계절감 등의 메타데이터를 자동으로 분류해 디지털 옷장을 구축해 줍니다. 

매일 아침 **사용자의 현재 위치 기준 실시간 날씨**와 **당일 일정/상황**을 종합 분석하여, 외부 제품 구매 추천이 아닌 **오직 내 옷장에 저장된 옷들로만 구성된 최적의 상·하의 코디 세트**를 선출하고 AI 스타일리스트의 추천 사유와 스타일링 팁까지 함께 제공합니다.

---

### 3. 핵심 목표 (Core Objectives)
* ⏱️ **의사결정 시간 단축**: 매일 아침 옷 고르는 시간을 절반 이상 단축
* 👕 **보유 의류 활용도 극대화**: 방치되는 옷 없이 가지고 있는 의류의 다양한 조합 연출
* 🤖 **AI 기반 개인화 경험**: 사용자 위치 날씨 API + generative AI 프롬프트 조합을 통한 맞춤형 큐레이션

---

### 🎯 주요 타깃 (Target Audience)
* 매일 아침 출근/등교 전 옷 선택에 어려움을 겪는 **대학생 및 직장인**
* 옷장에 옷은 많지만 매번 어떤 조합으로 입어야 할지 고민되는 **패션 입문자**
* 내 옷장 아이템을 한눈에 관리하고 스마트하게 활용하고 싶은 **모든 사용자**
