> **AI 기반 내 옷장 데이터 연동 & 날씨·일정 맞춤형 코디 추천 서비스**

## 📌 1. 프로젝트 개요 (Overview)

* **프로젝트명**: 오늘 뭐 입지?
* **개발 목적**: 사용자의 실제 보유 의류 데이터, 실시간 위치 기반 날씨 데이터, 당일 일정을 조합하여 **외부 쇼핑몰 옷이 아닌 오직 내가 가지고 있는 옷들로만 구성된 최적의 착용 코디**를 추천하고 AI 스타일리스트 피드백을 제공합니다.
* **주요 타깃**: 매일 아침 옷 선택에 어려움을 겪는 사람들
